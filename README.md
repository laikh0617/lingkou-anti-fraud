# 圈出詐騙｜嶺口國小防詐騙宣導

高雄市旗山區嶺口國民小學的防詐騙宣導網頁。用「老師紅筆批改」的方式圈出詐騙破綻，搭配 165 打詐儀錶板的最新數據和四款防詐小遊戲，讓孩子和家人一起看懂詐騙套路。

**網站：** https://laikh0617.github.io/lingkou-anti-fraud/

## 網頁內容

- **最新數據**：165 打詐儀錶板 115 年 9 月統計，包含受理件數、財損金額，以及前 5 名詐騙手法的件數和平均每件損失。
- **破解公式**：九種常見手法，各拆成「A＋B＋C＝詐騙」三個成分，並附上破解方法。
- **防詐遊戲場**：四款小遊戲，每過一關蓋一枚防詐章，集滿四枚就是「嶺口防詐小達人」。
  - **防詐全壘打**：答題推進壘包，答錯出局；可單人挑戰，也可紅隊、藍隊分組對抗。玩法參考樂活教育防詐棒球遊戲。
  - **真假快判**：判斷 10 則簡訊、通訊軟體訊息、來電和 Email 是詐騙還是安全。
  - **找出破綻**：在四個模擬畫面中點出 20 個詐騙破綻。
  - **來電應變**：三個情境，你的回應會走向「安全下莊」「驚險過關」或「被騙了」三種結局。
- **自我檢查**：勾選對方的要求，立即提示風險和下一步。
- **被騙怎麼辦**：四個求助步驟，以及 165、110 和官方查詢網站。

## 使用方式

整個網站只有一個 `index.html`，校徽也已經嵌在檔案裡，不需要安裝任何東西。

- 線上瀏覽：打開上方的網站網址。
- 離線使用：下載 `index.html`，用瀏覽器直接開啟（需要網路載入字型）。
- 放到學校網站：把 `index.html` 上傳到任一個網頁空間即可。

防詐章的紀錄存在瀏覽器本機。

## 成績收集（Google 試算表）

網頁可以把每一關的遊戲結果送到老師的 Google 試算表。`index.html` 裡的 `REPORT_URL` 留空時，不會傳送任何資料，也不會顯示班級座號欄位。

**會記錄的內容**：時間、班級、座號（學生選填）、匿名代號（每台裝置隨機產生）、遊戲與關卡、得分、答對與答錯題數、是否得章，以及逐題的作答與對錯。不收姓名。

**設定步驟**

1. 打開 https://sheets.new 建一份新的試算表，命名例如「圈出詐騙成績」。
2. 選單「擴充功能」→「Apps Script」。
3. 刪掉編輯器裡原本的程式，貼上 [`apps-script/Code.gs`](apps-script/Code.gs) 的全部內容，按儲存。
4. 上方函式選單選 `setup`，按「執行」。第一次會要求授權：選你的帳號 →「進階」→「前往（不安全）」→「允許」。這是你自己的程式，只會讀寫這份試算表。執行後會多出「成績總表」「逐題紀錄」「錯題統計」「班級統計」四個分頁。
5. 右上角「部署」→「新增部署作業」→ 齒輪選「網頁應用程式」→ 執行身分選「我」、誰可以存取選「所有人」→ 按「部署」。
6. 複製「網頁應用程式」網址（`https://script.google.com/macros/s/…/exec`），填進 `index.html` 的 `REPORT_URL`。

之後如果修改 `Code.gs`，要到「部署」→「管理部署作業」→ 編輯 → 版本選「新版本」再部署，網址才會維持不變。

**試算表分頁**

- **成績總表**：每玩完一關一列。
- **逐題紀錄**：每一題一列，包含學生的作答和結果。
- **錯題統計**：哪些題目、哪些破綻最多人答錯或沒找到。
- **班級統計**：各班各遊戲的遊玩次數和平均得分。

收集網址會出現在公開的網頁原始碼裡，有心人可以送假資料進來。程式會檢查資料格式並擋掉公式，但結果適合當教學參考，不適合當正式成績。
